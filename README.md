# magpie_bot

喜鹊助手是一个受到火柴工具（又叫火萤酱）启发的个人桌面助手。它可以全局呼出，快速进行文件检索、程序检索、翻译、计算器、智能体交互及功能拓展。

**Windows 优先交付，macOS 上开发**（先实现 Windows 产品，预留 macOS 可迁移性与拓展性）；开发遵循「框架先行、逐个功能实现」。
