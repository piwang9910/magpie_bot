# 喜鹊助手 · 需求摘要

> status: 已批准（2026-10-25，阶段1定稿）
> last_updated: 2026-11-25（开发环境再更正：Windows 主机承担开发、测试与验收；macOS 仅保留可迁移性）

## 1. 问题陈述

日常有四类高频动作，每次都要离开当前窗口、找入口、重新定位输入焦点：

| 场景 | 现在的代价 |
|------|-----------|
| 脑子里冒出一个概念，想搜 | 切浏览器 → 新标签 → 输入 |
| 算个数 | 找计算器 App / 打开系统计算器 |
| 查一个单词 | 切浏览器 / 打开词典 App |
| 打开某个本地文件或程序 | 找文件夹、翻开始菜单 |

目标：**一个全局快捷键唤出的悬浮框，默认本地搜索，Tab 切 AI，四类动作在同一个输入框里完成。**

## 2. 目标用户

- v1 用户：作者本人。**Windows 主机同时承担开发、测试与验收**；macOS 仅做可迁移性回归（同源码可编译，不参与验收，见 PLAN §3.5）。
- 非目标：多人协作、团队权限、外部商业化用户。

## 3. 核心需求与优先级

### P0（v1 必须交付）

| # | 需求 | 说明 |
|---|------|------|
| 1 | 悬浮框 | **双击 Ctrl** 唤出（键盘钩子后端）；Alt+Space 兜底（RegisterHotKey 后端）；置顶；失焦隐藏；全键盘可操作，不依赖鼠标 |
| 2 | 搜索调度器 | 默认本地；Tab / Ctrl+Tab 切换 AI 输入态；空输入显示空态提示（启动器网格见 P1-8）。**纯本地能力实时出结果，需要发请求的（AI、翻译）按 Enter 触发** |
| 3 | 本地搜索 | Everything SDK，覆盖文件 / 文件夹 / 已安装程序；结果可打开、定位所在文件夹、复制路径 |
| 4 | 计算器 | 自动识别表达式，结果作为卡片置于结果列表顶部，不挤占文件结果；回车复制 |
| 5 | 翻译 | 触发词唤起，Enter 触发，走模型网关；**与火柴一致，全程在悬浮框内完成**：结果作为卡片进入结果列表，不打开任何独立窗口 |
| 6 | AI 直答 | **真实调用 DeepSeek API**（不做 mock），流式输出。v1 不联网、不带来源引用 |
| 7 | 会话面板 | **仅服务于 AI 搜索**，不承载翻译、计算器或本地结果。独立窗口，可拖动、可调整大小，不随失焦隐藏，Esc 退出；v1 关闭即结束会话，不持久化历史 |

### P1（v1 尽量，可延期）

| # | 需求 | 说明 |
|---|------|------|
| 8 | 启动器网格 | **只显示手动配置的固定项**，键盘方向键选择；不做自动高频、不列开始菜单全量 |
| 9 | 明暗主题 | 只用 CSS 变量切换，不做皮肤文件格式 |
| 10 | macOS 本地搜索 | mdfind 实现，仅作可迁移性回归（非验收项） |

| # | 需求 | 留白方式 |
|---|------|---------|

| 12 | 登录 / 权限 / 商业化 | 只留身份接口 + 模型网关的额度检查点，不做登录 UI |

## 4. 技术约束

| 项 | 决定 |
|----|------|
| 框架 | Tauri 2（Rust 后端 + TypeScript 前端） |
| 交付平台 | Windows（开发、测试与交付同一主机）；macOS 保留可迁移性，不做验收 |
| Rust 职责 | 系统集成薄层（全局热键、窗口显隐、托盘、打开/定位文件）、本地搜索厚模块（Everything FFI）、模型网关（Key 管理与流式代理） |
| TS 职责 | 搜索调度器状态机、全部 UI、小程序注册表、计算器逻辑 |
| 平台隔离 | 所有平台专属代码必须用 `cfg(target_os)` 隔离，**且只集中在少数几个文件**（热键 `_win.rs`、搜索 `everything_win.rs`、`window.rs` 的 `cfg(windows)` 分支）；Windows 为开发机+验收机，`cargo check` 覆盖全量（含 `cfg(windows)` 分支）；macOS 仅做可迁移性回归，只覆盖跨平台模块；同源码双端可编译 |
| 构建链路 | 各平台本地构建，不做交叉编译；源码经 git 同步，不在坚果云目录内跑构建（排除 `node_modules/`、`target/`、`dist/`） |
| 密钥 | API Key 存系统凭据库（Windows Credential Manager / macOS Keychain），不下发到前端 |
| 模型 | DeepSeek，OpenAI 兼容接口，Key 已具备 |
| 全局热键 | 双击 Ctrl 无法用 RegisterHotKey 实现，必须用低级键盘钩子（WH_KEYBOARD_LL）；需处理与 Ctrl 组合键的互斥。同时实现 RegisterHotKey 后端（Alt+Space）作为兜底，两套后端共用同一热键抽象 |
| 第三方许可 | Everything 采用 MIT 许可，可自由分发、修改、商用，只需保留版权声明；不可冒用 voidtools 品牌 |
| 跨窗口状态 | 悬浮框与会话面板是两个独立 webview，不共享前端状态；初始输入经窗口启动参数传递，会话状态只存在于面板内 |
| 权限声明 | 每个窗口一份 capability（`hud` / `panel`）。新增 Rust command 与前端调用，必须同批更新权限声明；漏配时编译期无感、运行期被拒 |
| 常驻 | 单实例；托盘常驻；内存实测后定阈值 |
| 轻量红线 | **不引入重型运行时**（Python / PyTorch / 常驻 Node 服务 / 本地大模型）。TTS、OCR、格式转换等重依赖能力，一律走系统 API 或独立可选工具（外部 CLI 代理），不并入主进程 |

## 5. 验收标准

单人自测，用日志时间戳记录，不要求自动化测试套件。

| # | 项 | 阈值 |
|---|---|------|
| 1 | 已运行状态唤出悬浮框 | ≤ 150ms 可见且可输入 |
| 2 | 冷启动到可输入 | ≤ 800ms |
| 3 | 本地模式键入 3 字符后首个结果 | ≤ 300ms（Everything 索引就绪） |
| 4 | 应用启动命中 | 输入前 4 个字母，目标程序进前 3 |
| 5 | 计算器回车出结果 | ≤ 100ms |
| 6 | 翻译首字输出 | ≤ 1.5s，且结果出现在悬浮框内、不打开新窗口 |
| 7 | AI 直答首字 | P50 ≤ 2.5s，整段 ≤ 15s |
| 8 | 常驻内存 | 待 Windows 实测校准；初版目标 ≤200MB，实测后定稿 |
| 9 | 未安装 Everything 时 | 应用仍能启动，本地搜索给出明确降级提示，不静默失败 |
| 10 | 键盘闭环 | 从唤出到打开任意结果，全程不碰鼠标 |
| 11 | 会话面板 | Esc 立即关闭，焦点回到原应用 |

## 6. 交互定义

### 6.1 键盘映射

| 按键 | HUD · 空输入 | HUD · 本地输入 | HUD · AI 输入态 | 会话面板 |
|---|---|---|---|---|
| 双击 Ctrl | 唤出 / 隐藏 | 同左 | 同左 | 唤出 HUD 并聚焦输入 |
| ↑ / ↓ | 网格选择 | 结果选择 | — | 消息区滚动 |
| Enter | 执行选中项 | 打开 / 执行选中项 | 发送问题，打开面板并隐藏 HUD | 发送追问 |
| Tab | — | 切到 AI 输入态 | 切回本地 | — |
| Ctrl+Tab | 同 Tab，任何状态都生效 | 同左 | 同左 | 切回 HUD |
| Esc | 隐藏 | 清空输入；已空则隐藏 | 回到本地模式 | 关闭面板，焦点回原应用 |
| Ctrl+C | — | 复制选中项路径 | 复制当前答案 | 复制当前消息 |

组词状态（IME composition）下：Tab 交给输入法，Ctrl+Tab 仍生效，Enter 交给输入法上屏。

### 6.2 界面状态清单

HUD：

| 状态 | 触发 | 展示 |
|---|---|---|
| 空闲 | 唤出且无输入 | 启动器网格 |
| 空闲 · 未配置固定项 | 唤出、无输入、固定项为空 | 提示“在设置中添加启动项” |
| 搜索中 | 有输入、本地、结果未返回 | 保留上次结果 + 顶部细进度条 |
| 有结果 | 本地结果返回 | 结果列表，计算卡片置顶 |
| 无结果 | 查询无命中 | “无匹配” + 建议切 AI 模式 |
| 降级 | Everything 不可用 | 程序搜索结果 + 一行安装提示 |
| AI 输入态 | Tab 切换 | 输入框视觉变化 + “Enter 发送”提示 |

面板：

| 状态 | 触发 | 展示 |
|---|---|---|
| 提问中 | Enter 发送后 | 用户消息 + 等待骨架 |
| 流式中 | 首个 token 到达 | 逐字追加 + 中断入口 |
| 完成 | 流结束 | 完整回答 + 复制 + 追问输入框 |
| 已中断 | 用户中断 | 半截内容 + “已中断”标记 |
| 错误 | 网络 / 鉴权 / 限流 | 错误文案 + 重试按钮 |
| 追问中 | 面板内再次 Enter | 追加用户消息，回到流式 |

### 6.3 设置项（v1）

| 项 | 默认 | 说明 |
|---|---|---|
| 热键后端 | 双击 Ctrl（钩子） | 可切 Alt+Space（RegisterHotKey） |
| 双击间隔阈值 | 400ms | 可调 250–600ms |
| 开机自启 | 关 | — |
| 主题 | 跟随系统 | 明 / 暗 / 跟随 |
| 结果条数 | 20 | 5–50 |
| 启动器固定项 | 空 | 手动添加程序或文件夹，键盘可增删排序 |
| 常驻灵动岛态 | 关 | 类似 iPhone 灵动岛的常驻展示，**设置中可开/可关**；只展示喜鹊自身状态，功能后续实现（见 PLAN ADR-7） |
| 清空最近打开记录 | — | 清空评分层数据 |

### 6.4 数据留存

| 数据 | 是否落盘 | 说明 |
|---|---|---|
| 输入内容 | 否 | 日志只记耗时与状态码 |
| 最近打开项 | 是（本地） | 仅用于排序权重，可清空 |
| AI 会话 | 否 | 面板关闭即丢弃 |
| API Key | 是（系统凭据库） | 前端不可读 |

### 10.1 快速检索来电归属（#16）

**功能概述**

在悬浮框内直接输入手机号或座机号，返回归属地（省 / 市）、运营商与号段类型。不做通讯录、不做通话记录，只回答「这个号码是哪儿的」。

**核心使用场景**

| # | 场景 | 用户动作 |
|---|------|---------|
| 1 | 陌生号码错过了来电，想知道是哪儿的 | 双击 Ctrl → 粘号码 → 归属卡片直接置顶 |
| 2 | 核对客户 / 供应商号码是否与其自称的国家或地区一致 | 输入 E.164 号码，看国家与省份是否对得上 |
| 3 | 收到一段含号码的文本，只想快速确认 | 粘贴整段，号码被识别并出卡片，文本原样保留 |

> 场景 2 是外贸业务的真实刚需：询盘里号码与自称地区对不上，是判断真假的一条低成本线索。

**预期实现逻辑**

| 环节 | 设计 |
|---|---|
| 形态 | 小程序（MiniApp），走统一输入 / 输出契约，不侵入调度器 |
| 触发词 | 候选 `gs` / `归属`；另允许**无触发词识别**——整串可解析为号码时置顶卡片（与计算器同一判定原则：整串可解析才算，`电话13800138000` 判为文件搜索） |
| 归一化 | 去空格 / 横线 / 括号；`+86`、`0086`、`86` 前缀剥除；区分 11 位国内手机、0 开头座机、E.164 国际号 |
| 数据源 L1 | 离线号段库：手机号前 7 位 → 省 / 市 + 运营商；座机区号 → 城市。随版本附带，可热更 |
| 数据源 L2 | 在线补充：国际号码、虚拟运营商、新号段。**须显式 Enter 触发**，与 AI / 翻译同理，不边打字边发请求 |
| 网络边界 | L2 不走模型网关（不是模型调用），独立 HTTP 客户端 + 独立超时与限流 |
| 隐私 | 号码不写入日志、不落盘；L2 默认关闭，设置里显式开启并说明「会向第三方发送号码」 |
| 输出卡片 | 归属地 / 运营商 / 号段类型；Enter 复制号码，Esc 隐藏 HUD；无结果时给「未收录号段」而不是空列表 |

**优先级标注**

**P2 —— v1 不实现。** 理由有三：

1. v1 的核心承诺是「本地检索毫秒级」，归属查询是低频动作，不该挤占首版验收带宽
2. 号段库是持续维护的外部数据，会撑大安装包并引入更新义务
3. 归属数据一旦要「准确」，就必须有人负责更新；首版没这个人手

v1 只留两处：小程序注册表里的占位、调度器里「整串是否号码」的判定位置。

**待后续补充（开发前必须定）**

1. **号段库来源与许可**：能否再分发、能否商用；若不可，则必须改成纯在线方案
2. **国际号支持程度**：E.164 → 国家容易，省市几乎不可能离线做全；需要明确「国际号只答国家」这一降级口径
3. **明确排除骚扰 / 诈骗标记**：涉及数据合规与投诉风险，本功能只做归属地，不做信誉标记
4. **离线库体积上限**：建议 ≤ 2MB，超出则改为首次使用时下载
5. **剪贴板取数边界**：唤出 HUD 时是否自动读剪贴板预填？默认**不自动**，避免把剪贴板里的密码之类带进输入框
6. **验收阈值**：离线查询 ≤ 50ms；在线补充 ≤ 1.5s（与翻译同档）
