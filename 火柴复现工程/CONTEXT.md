
# 项目上下文 (CONTEXT.md)

> 纯术语表，不含实现细节。最后更新: 2026-11-23（开发环境更正为 macOS；整合岛仔形态参考术语）

## 项目概述

- 名称：喜鹊助手（原名「澎湃助手」，2026-10-27 改名）
- 一句话描述：以火柴/火萤酱的悬浮式入口为形态的桌面效率工具，**Windows 优先交付、macOS 上开发**；默认本地搜索，Tab 切入 AI 直答。

## 通用语言 (Ubiquitous Language)

| 术语 | 含义 | 备注 |
|------|------|------|
| 喜鹊助手 | 本项目的产品名称 | 原内部代号「澎湃助手」，因与澎湃新闻同名于 2026-10-27 改名 |
| 火柴 / 火萤酱 | 参考产品，Windows 上的悬浮式搜索启动器，本项目形态来源 | 不是本项目名称 |
| 悬浮框 | 全局快捷键唤出的置顶输入浮层，产品的唯一主界面 | 空态与输入态是同一浮层的两种渲染 |
| 搜索调度器 | 接收「输入字符串 + 当前模式」，决定这次输入去向的唯一编排层 | 自身不做系统调用 |
| 模式 | 悬浮框输入语义的当前取值：本地 / 网络 | 默认本地，Tab 切换到网络 |
| AI 直答 | 网络模式在 v1 的实际形态：模型直接回答，不联网、不带来源 | 联网搜索是 v2，不进入 v1 验收 |
| 触发词 | 输入开头的已注册关键字，用于把输入路由到小程序 | 路由时被剥离 |
| 小程序 (MiniApp) | 由触发词唤起的独立能力单元，实现同一输入/输出契约 | 可增删，不侵入调度器 |
| 启动器网格 | 悬浮框无输入时展示的快捷启动项 | 输入非空时让位给结果列表 |
| 本地搜索后端 | 检索本机文件/文件夹/应用的模块，对外只暴露单一查询接口 | v1 用 Everything SDK；macOS 侧用 mdfind 或桩实现 |
| AI 搜索子代理 | 网络模式的编排层：v1 只调用模型，v2 才接入 Search / Fetch 工具 | 产出带来源引用的回答 |
| 模型网关 | 所有模型调用必须经过的唯一入口，内含身份/额度检查与 Key 管理 | 既是安全边界，也是将来商业化的计费点 |
| 结果卡片 | 单条搜索或小程序输出的统一展示单元 | 打开、预览、二次动作挂在其上 |
| 薄桥接层 | Rust 侧只做系统能力转发的部分 | 与「厚模块」相对 |
| 厚模块 | 逻辑集中在内部、但对外接口极简的模块 | 典型：本地搜索后端 |
| 跨平台抽象 | 把平台差异（Windows / macOS）隔离在接口之后的层 | Windows 先行，macOS 预留 |
| 皮肤 | 明暗两套主题，通过变量切换 | 不做皮肤文件格式，不做皮肤编辑器 |
| PeerService | 局域网 / 文件快传能力的预留接口 | 本期不实现 |
| 热键后端 | 触发悬浮框的实现方式：键盘钩子（双击 Ctrl）或 RegisterHotKey（组合键） | 两套后端共用同一层热键抽象 |
| 身份接口 | 预留的登录/授权抽象，v1 只有「本机本人」一种实现 | 为将来权限管理与商业化留位，不做登录 UI |
| 外部 CLI 代理 | 小程序的一种实现方式：不自带引擎，调用本机已装的命令行工具完成能力 | 首个用例：格式转换走 Filee 的 `filee convert`；工具缺失时该小程序自动隐藏 |
| 两态展开 | 借自岛仔的形态语言：HUD 从顶部细横条展开成输入框（带回弹），卡片向下展开 | 只借视觉节奏；需实测展开时输入焦点不丢 |
| 常驻灵动岛态 | 类似 iPhone 灵动岛的常驻展示形态，独立于按需唤出的 HUD | 设置中可开/可关，默认关；只展示喜鹊自身状态，不做岛仔的信息面；先留框架位后实现（ADR-7） |
| 分区契约 | 喜鹊与岛仔的零代码共存约定：岛仔顶部停靠，喜鹊居中偏上唤出并留顶部安全距 | `avoidTop = 140pt`，避免唤起时遮住岛体 |
| 竖切 | 用一条最小的端到端功能验证框架是否可用 | v1 第一条竖切是计算器；先验证框架再做其他功能 |
| 开发机 / 验收机 | macOS 是日常开发机；Windows 是交付与验收目标机 | 旧稿「Windows 主开发」表述已作废 |
| TriggerRegistry | 小程序路由层：维护触发词→处理器的映射，只做匹配、剥离、转发 | 不关心处理器内部实现；新增小程序不改调度器 |

## 关键约定

- 文档语言：中文；代码标识符用英文。
- 术语以本表为准；新术语确认后立即补充，不批量延后。
- 每个能力都必须回答：它在悬浮框里长什么样、怎么只用键盘到达。
